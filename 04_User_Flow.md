# USER FLOW

## Linear MVP Flow
HomePage → /app → BlueprintForm → /system/viability → /system/results → BlueprintDeliveryPackage → ZIP Download

## Step 1 — Entry
The user arrives on HomePage and understands that ForgeBlueprint Project creates a build-ready MVP package.

## Step 2 — Intake
The user enters:
- project idea
- target audience
- product type
- monetization direction
- risk or constraint

## Step 3 — Viability
The system evaluates if the project is ready to build, needs adjustment, or should be rejected.

## Step 4 — Results
The system shows the executive blueprint with decision, priority, risk, and execution direction.

## Step 5 — Delivery
The user downloads the ZIP package containing all 11 execution files.

## Step 6 — Optional GitHub
The user can open the GitHub version without affecting ZIP delivery.
